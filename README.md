# Regicide

> 一个基于 Python 的命令行合作类卡牌游戏，与伙伴共同击败 BOSS，改编自《弑君者》。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python Version](https://img.shields.io/badge/python-3.14%2B-blue)](https://www.python.org/)

## 下载 | 安装

### 环境要求

- Python 3.14.6+
- 无需任何第三方库

### 安装与运行

- 前往Release界面下载.exe文件
- 或用源文件直接运行：
    1. 克隆仓库
    ```bash
    git clone https://github.com/FeSo4a/regicide.git
    cd regicide
    ```
    2. 运行游戏
    ```bash
    python main.py
    ```
  
#### 运行示例

- 若不想指定参数，双击main.py/exe文件打开即可
- 想修改配置时，在cmd中输入以下内容即可查看说明
```bash
cd src
python main.py -h 
```
- 修改配置示例
```bash
cd src
python main.py config -l ../log # 设置日志的路径
python main.py config -o y  # 开启记录日志的功能
```

### 游戏规则说明

#### 胜利条件

- 击败全部12个Boss时游戏胜利
- 玩家死亡时游戏失败

#### 游戏准备

1. 分离Boss牌
    - 从牌堆中取出所有 J、Q、K（共12张）。
    - 洗牌后按 J（上）→ Q → K（下） 叠放，形成Boss牌堆。
    - 翻开最上面1张作为当前Boss，展示其花色与数值。
2. 玩家手牌分配（严格按人数，当然我没做多人模式）
    - 1人：8张
    - 2人：7张
    - 3人：6张
    - 4人：5张
    - 规则：手牌上限固定，任何时候不得超过初始数量。
3. 牌堆设置
    - 剩余牌（A-10）洗牌，作为抽牌堆（Draw Pile）。
    - 打出/弃掉的牌放入弃牌堆（Discard Pile），不可洗牌。

#### Boss属性

| Boss	      | 血量（HP）	 | 攻击力（ATK）	 | 免疫                               |
|-----------|------------|---------------|------------------------------------|
| J（杰克） | 	10	         | 20	            | 自身花色（仅免疫效果，不免疫伤害） |
| Q（皇后） | 	15	         | 30	            | 自身花色                           |
| K（国王） | 	20         | 	40            | 	自身花色                           |

- 免疫规则：Boss对自身花色的能力完全无效，但仍受该花色牌的点数伤害。
    - 例：红心J → 玩家打出♥时，仅造成伤害，不触发回牌效果。

#### 花色能力

1. 基础花色（2–10）
    - ♣ 梅花（攻击）：伤害×2（例：♣5 = 10点伤害）
    - ♠ 黑桃（防御）：降低Boss当前攻击力，数值=牌面点数；仅当Boss死亡时效果解除
    - ♦ 方片（抽牌）：所有玩家轮流抽牌，总张数=牌面点数；不超过手牌上限
    - ♥ 红桃（回牌）：从弃牌堆随机抽点数张数的牌，洗回抽牌堆底部
2. A（Ace，伙伴）
    - 单独打出：伤害1点，触发自身花色能力。
    - 组合打出：可与任意1张牌一起出（A+X），同时触发：
        - 两张牌的点数相加（A=1）
        - 两张牌的花色能力叠加
        - 例：A♠ + 5♦ → 总伤害6，Boss攻-6，全体抽6张。
3. 小丑（底牌，我把它做成了类似大招一样的东西，尽可能少使用可以获得更高评价）
    - 必须单独打出，无伤害。
    - 效果（二选一）：
        1. 解除免疫：抹除Boss当前花色，所有花色能力生效。
        2. 将手牌全部弃掉，并抽到手牌上限

#### 回合流程

1. 出牌：
    - 程序提示示例：
    ```text
    剩余Boss：11
    现在的Boss: ♠J
    Boss血量：20
    Boss伤害：10
    
    卡池情况：32 剩余卡牌 | 0 弃牌区
    
    玩家护甲：0
    玩家剩余底牌：2 （出牌阶段输入joker即可使用）
    [1] ♥5 [2] ♣5 [3] ♠5 [4] ♣8 [5] ♠9 [6] ♠6 [7] ♣3 [8] ♠A
    请输入要出牌的序列号，如果要出多张牌请勿分割：
    ```
    - 输入牌的序列号即可出牌
    - 出牌应遵守规则：
        - 同点数组合：多张同点数牌（如3♣+3♠+3♦），总点数≤10。
        - A组合：1张A + 1张任意牌（A+X），无点数上限。
        - 单张：任意单张（含A、小丑）。
    - 示例：出一张♥5和一张♣5（两张总点数5+5恰好≤10）
    ```text
    1 2
    ```

2. 结算能力：
    - ♣（攻击） → 计算总伤害
    - ♠（防御） → 降低Boss攻击力
    - ♦（抽牌） → 全体抽牌
    - ♥（回牌） → 弃牌回抽堆
    - 免疫优先级：Boss免疫的花色，能力不触发，但伤害仍计算。
    - 程序提示示例：
   ```text
   你出了10点数！
   你发动了♥花色技能！
   已将弃牌区中的10张牌加入牌库！
   回车确认
   ```
    - 此时按下回车即可进入下一步

3. 伤害判定：
    - 总伤害 = 所有打出牌点数之和（梅花×2）。
   ```text
   你对Boss造成了10点伤害！
   回车确认
   ```
    - 扣除Boss当前血量：
    - 血量＜0：Boss被击杀 → 放入弃牌堆，翻开下一张Boss。
    - 血量＝0：Boss被感化 → 放入抽牌堆顶，后续可当普通牌使用（J=10、Q=15、K=20）。
    - 血量＞0：进入反击阶段。
    - 程序提示示例：
   ```text
   Boss血量恰为0，你感化了Boss！
   回车确认
   ```

4. 防御阶段：
    - Boss攻击：对当前玩家造成当前攻击力的伤害。
    - 防御：玩家必须弃掉手牌，使弃牌总点数≥Boss攻击力。
    - 可用黑桃减攻后的数值计算防御需求。
    - 弃牌按任意顺序，点数可叠加。
   ```text
   Boss对你造成了10点伤害！
   [1] ♦9 [2] ♦3 [3] ♦A [4] ♣7 [5] ♣8 [6] ♣10 [7] ♠2 [8] ♥6 
   请弃掉比伤害数量大的牌，可弃多张：
   1 3
   ```
    - 失败惩罚：弃光手牌仍不足 → 该玩家阵亡，全队游戏结束。
   ```text
   失败......
   击败Boss: 1 / 12
   评级：F
   ```

#### 胜利评级

- 使用两张小丑牌：B
- 使用一张小丑牌：A
- 不使用小丑牌：S
